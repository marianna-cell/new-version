# Knowledge Wars ⚔️

Геймифицированный трекер учёбы: проходишь карточки — «захватываешь» клетки на карте знаний.
Чем больше правильных ответов, тем больше клеток твоего цвета.

> **О стеке.** Платформа собирает статические сайты (без Node/Next.js и серверных роутов),
> поэтому MVP реализован на чистом HTML + ES-модулях с той же архитектурой:
> отдельные слои `store` (данные/состояние), `views` (экраны), `data` (контент), `ui` (примитивы).
> Логика, экраны и критерии готовности — те же. Слой `store.js` изолирован, поэтому переезд
> на Supabase (или перенос в Next.js App Router) — это замена одного файла, а не переписывание.

## Запуск

Приложение полностью статическое (HTML + ES-модули), сборка не требуется.

```bash
# любой статический сервер из корня проекта
python3 -m http.server 8000
# или
npx serve .
```

Открой `http://localhost:8000`.

> ⚠️ Открывать `index.html` через `file://` нельзя — ES-модули и `fetch` требуют HTTP.
> Service worker (PWA) работает только на `localhost` или HTTPS.

## Экраны

| Экран | Что делает |
|---|---|
| **Вход / регистрация** | Email + пароль (хешируется), имя. Два режима: «Войти» / «Зарегистрироваться» |
| **Карта знаний** | Сетка 5×5 для выбранного предмета. Статусы: locked / available / captured / captured_by_other |
| **Тема** | 10 карточек: вопрос + 4 варианта, один верный |
| **Результат** | ≥ 8/10 (80%) → клетка захвачена, 100%, конфетти. Иначе прогресс сохраняется |
| **Профиль** | Email, имя, захваченные клетки, streak, очки, сброс/выход |
| **Лидерборд** | Топ-10: 5 соперников + ты |

## Предметы

Переключатель предмета — в шапке игры (и на лендинге). У каждого предмета своя карта 5×5
и свой прогресс; выбор сохраняется в `localStorage` под ключом `kw:subject`.

| id | Предмет | Тем |
|---|---|---|
| `math` | Математика | 25 |
| `russian` | Русский язык | 25 |
| `physics` | Физика | 25 |
| `english` | Английский язык | 25 |
| `ege_math` | ЕГЭ Математика (профиль) | 25 |

Итого 125 тем × 10 вопросов = 1250 вопросов.

## Как добавить/изменить вопросы

1. Учебный план (названия и иконки тем) — `/data/topics.json`.
2. Вопросы — `/data/banks/<subject>.js`. Формат строки:
   `вопрос~правильный ответ~неверный~неверный~неверный` (разделитель `~`).
   Варианты перемешиваются детерминированно, поэтому порядок в файле не важен.
3. Ключ объекта = `id` темы из `topics.json`. Нужно ровно 10 строк на тему.


## Замена контента

Отредактируй `data/topics.json` — единственный источник карточек:

```json
{
  "subject": "Математика ЕГЭ",
  "topics": [
    {
      "id": "percent",
      "title": "Проценты",
      "icon": "%",
      "questions": [
        { "q": "Сколько 15% от 200?", "o": ["20", "30", "35", "45"], "a": 1 }
      ]
    }
  ]
}
```

`a` — индекс правильного варианта (0–3). Тем должно быть 25 (сетка 5×5).

## Логика захвата

- Стартовая клетка — центр карты (индекс 12), она открыта сразу.
- Новые клетки открываются рядом с уже захваченными.
- 5 клеток изначально заняты соперниками (серые) — их нельзя захватить в MVP.
- 80%+ правильных → клетка твоя, +150 очков; каждый верный ответ +20.
